# xkcd-search

Небольшая распределённая система, которая индексирует комиксы [xkcd](https://xkcd.com) и позволяет искать их по тексту

## Основные возможности

- **Загрузка данных**: скачивание комиксов с xkcd, сохранение метаданных и поискового текста, уведомления сервисов через **NATS**
- **Поиск**: поиск по фразе с настраиваемым лимитом;
- **Сервис words**: gRPC-служба нормализации / токенизации текста для update и search
- **Авторизация**: `POST /api/login` выдаёт JWT;
- **Метрики**: эндпоинт `/metrics` в формате Prometheus; **VictoriaMetrics** и **Grafana** 

## Запуск

```bash
docker compose up --build
```
